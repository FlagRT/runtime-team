## 1. 运行时层子方向与职责域（依据模块拆分表 + 战略文档）

运行时层四个子方向（战略文档 §5）+ 协调层：

| 子方向 | 职责域（模块拆分表） | 标注 |
|---|---|---|
| **device-context（我们）** | **设备抽象与执行上下文**（全模块，红）：设备/内存/执行句柄、Stream/Event 与错误处理、页锁定内存与双缓冲、同步语义、错误码翻译、设备状态恢复 | 我们的主域 |
| | **监控诊断与可靠性**（部分，红）：算子与全链路指标采集、故障检测与多级恢复、模型热加载与多卡迁移 | 我们的延伸域 |
| | **精度与性能分析**（部分，红）：Oracle-Device 中间结果回归、性能 Profiling 助手 | 我们的延伸域 |
| communication | 多卡通信（张量/流水线并行、通信与检查点管理）——注：910C 上实际工作已由我们做过一遍，战略文档定为**共同承担** | 协同 |
| memory | 显存池与分层缓存、显存卸载 | 下层 |
| performance | 指标采集、性能评测、验收报告 | 下层 |
| 总组（协调层） | 镜像锁定维护、接口约定文档、合入把关、跨方向联调 | 协调 |

**分工原则（用户定的迭代循环）**：

```
device-context 交付底座组件（统一 API + 某芯片 backend）
        ↓
下层子方向（memory / performance / 调度等）基于底座做自己的开发
        ↓
使用中发现问题 → 反馈给 device-context（或对应 owner）
        ↓
device-context 修复迭代 → 新版本组件 → 下层更新
        ↓
每月底：各子方向交本月产物 → 总组合一稿 = 运行时层本月对外指标与产物
```

**合入把关**（沿用战略文档 §5 五项标准）：镜像与 stack.lock 一致 ② 命名合规 ③ 接口约定章节写完且有下游确认 ④ 能跑通自己那段 demo ⑤ 无新环境分叉。

## 3. 逐月分工细案

> 每月三段式：**【我们交付】→【下层使用与反馈】→【月底合稿】**。
> 标 🔁 的为组内迭代闭环点。

### 2026.09 —— 运行时原型（本月，模板月）

**【device-context 交付】**（大部分已完成 ✅）
1. 统一运行时 API 框架 + Backend 注册表 + ascend 后端（**已完成，真机 37/37**）
2. conformance 13/13 + 6/6（统一 API 跑通，**已完成**）
3. demo_unified（设备无关演示，**已完成**）
4. 🔲 **按战略文档补齐**（本周内）：
   - 2 卡分布式微调（Qwen3-Embedding-0.6B，锁定训练镜像，与 communication 共同）
   - 错误注入 → 统一识别 → 恢复闭环的**演示证据**（验收标准第 3 条）
   - 组件打包：三大句柄 + 流/事件 + 错误处理 + 状态管理 + 恢复逻辑 → **去除 torch_fl 历史命名痕迹**
   - 接口约定文档（设备执行上下文章节）
5. 🔲 **交付给下层**：runtime 组件包 v0.1（memory / performance / 调度方向接入使用）

**【下层使用与反馈】**🔁
- memory：基于我们组件做显存画像（锁定推理镜像）
- performance：基于我们组件采集性能数据
- 反馈渠道：接口问题/缺陷 → device-context 修复 → 组件 v0.1.x

**【月底合稿】**
- 统一验收报告（5 项验收标准逐条对应）：device-context 供 §1/§3 证据、communication 供通信正确性、memory 供显存画像、performance 供报告汇总
- **对外产物 = 运行时原型 + 验收报告**

### 2026.10 —— 首批推理链路（≥20 模型 × 1 芯片）

## 4. 月底合稿机制（制度化）

```
每月 20 日   各子方向自检：本月产物是否覆盖 §2 对应指标
每月 22 日   交叉评审：相邻子方向互查（device-context ↔ memory ↔ performance）
每月 25 日   各子方向向总组提交：产物清单 + 证据链接 + 遗留问题
每月 26-28 日 总组合稿：运行时层月度报告（对外指标逐条对应产物）
每月底       提交 + 下月计划发布（含组件版本发布说明）
```

**合稿固定章节模板**（运行时层月度报告）：
1. 本月考核指标逐条对照（产物/证据）
2. 各子方向交付明细
3. 组内迭代记录（我们组件的下发版本 × 下层反馈 × 修复闭环）
4. 遗留与下月输入
