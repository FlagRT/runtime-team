- 编译三连排障：`TORCH_DEVICE_BACKEND_AUTOLOAD=0`（torch 2.10 autoload）→ `ACCELERATOR=ascend`（默认 cuda）→ **patch setup.py 补 `-DFLAGGEMS_KERNEL=OFF`**（CMakeLists 该 option 默认 ON 但 ascend 分支漏强制 OFF，上游缺陷，dcu/musa/bpu 均有）

### 4. 源码版实测新发现（重要，已入脚本与回归指南）

| 坑 | 现象 | 对策 |
|---|---|---|
| pin_memory 段错误 | flagos 设备未初始化时 `pin_memory()` 段错误（EXIT=139） | 设备预热 `torch.zeros(1, device="flagos")` |
| E2 先 wait 后 record 死锁 | `flagos.Event().wait()` 未 record 时永久阻塞 | 统一层需定义超时/语义收敛 |
| torch.cuda 误报 | flagos 下 `torch.cuda.is_available()` 返回 True 但 +cpu torch 的 Event/synchronize 不可用 | 统一用 `flagos.synchronize()` |
| 数值容差 | aclnnMatmul 与 CPU matmul 数值差异（相对 ~2e-5） | 一致性用例用相对容差 1e-3 |
