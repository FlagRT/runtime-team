## 3 本轮核出的三个环境事实（都已写进手册坑 25）

1. ⭐ **`--privileged` 下挂载白名单不生效**：容器内可见 16 个 `/dev/davinci*`，
   于是 `ASCEND_RT_VISIBLE_DEVICES=n` = **物理 die n**，而不是 `--device` 挂的那张。
   实证：只挂 `davinci6` 的容器里设 `ASCEND_RT_VISIBLE_DEVICES=0` 分配 2 GiB ⇒ **物理 die0** 上涨 2,113 MB。
   ⇒ 以后 privileged 容器**不按 0 基心算选卡**，一律给物理 die 号并用分配差值实证。
2. ⭐ **`npu-smi` 的 HBM 读数有 10~20 s 滞后**：分配后立即读可能仍是基线、进程退出后仍高位停留十几秒。
   ⇒ 峰值要在服务稳定 ≥25 s 后采；释放判据要等 ≥22 s 再读。
3. 该镜像每次 `bash -lc` 会打印 `can not use command: npu-smi info`（容器内无 npu-smi）⇒
   重定向进 JSON 会污染首行（本轮 sha JSON 因此需"找第一个 `{`"容错）。
