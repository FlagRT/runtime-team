本 PR 交付**设备执行上下文职责**在昇腾 910C 上的完整验收成果，覆盖

## 5. 关键发现（可复用）

### 5.1 训练侧

1. **event 资源泄漏（真实缺陷，已修复）**：训练每步累积 ~120 个 `aclrtEvent`，
   补析构 + work 完成语义。**这是长跑才会暴露的问题**——短跑测试发现不了，
   提示验收必须包含足够步数的长跑。
2. **吞吐差距已定位挂账**：flagcx vs hccl 的差距已定位，移交通信方向（非本方向阻塞）。
3. **回补 D8 时保持 num_workers=0**：容器内 fork 子进程有风险，
   最小变更只加 `pin_memory` + `non_blocking`，语义等价、数值不变。

### 5.2 推理侧

1. **TP 数值等价对照（纪律级，结论已修正）**：
   随机采样下 TP=1/2 **必然发散**；greedy 下一致性显著提升但**并非逐字一致**
   （16×256 复测 4/16 全长一致、50.1% 一致 token）。
   **判定缺陷应看「随机性 / NaN / 乱码 / 语义崩坏」，不是「与 TP=1 逐字不同」**。
2. **ACL 107015 根因（stream callback 契约）**：stream 未 subscribe 即 launch callback。
   A/B 单变量对照 + **可逆性 E4**（subscribe→unsubscribe→launch 复现）确立因果。
3. **错误码映射表优先级高于消息语义**：CANN 头文件即权威错误码全集（159 个），
   不需要攒错误示例；高置信差异人工裁决后固化防漂移。
4. **环境结论：A 线走 vllm-ascend 官方镜像**：`vllm-plugin-FL` 无 ascend 后端（坑 A5）。

### 5.3 双侧共用

5. **多流 `record_stream` 硬纪律**：PyTorch 缓存分配器跨流复用内存必须
   `tensor.record_stream(using_stream)`，否则内存可能被提前回收重用 → 数据竞争。
   （已据此修复双缓冲 v2 实现缺口）
6. **错误隔离分层**：API 级错误只影响该次调用（其他流不受影响，已实测）；
   芯片级错误（AICORE_TIMEOUT/EXCEPTION）影响该设备全部流，
   **恢复须走设备级 `aclrtResetDevice`，流级重试无效**。
