## 执行序与偏离声明（PLAN §8 边界内·操作层）
1. **ON 链先于 OFF 链**（先例为 OFF 先）：理由=部署态为 ON 引擎且零请求（23:20 起），指令要求不重启已部署 serve；A/B 差分不受影响（两引擎各自全新引擎史、固定表逐字一致，唯一差分=kv-transfer-config 有无）
2. P(ON) 稳态采样窗口偏离（见上，零请求平台等价）
3. 引擎切换 ON→OFF = 唯一一次协议必需的 serve 重启（PLAN §1：两档间切换=重启重挂，引擎史重置，如实记录；不涉及容器重启）
4. R 腿 reference=OFF 引擎输出（同 prompt temperature=0 基线引擎），另加同引擎史 L 重放逐字对照；第三方独立 reference（如 HF transformers 重算）不可用（xpu5 无余量加载第二份权重，9.88 GiB free < 15.63 GiB）——"可用时"条款下的如实记录
