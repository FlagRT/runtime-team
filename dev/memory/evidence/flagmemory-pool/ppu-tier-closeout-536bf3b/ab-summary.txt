## 诊断标记计数（ab-serve-b.log）

- [PpuOffload-DMA] store：123 批次，累计 398 块（24 层）
- [PpuOffload-DMA] load：4 批次，累计 8 块（召回实锤，18:40:40-45）
- [PpuOffload-SCHED] entry：多次；hit_len 非 0 命中 4 次（最高 hit_len=80）

召回触发剧本（ab_recall_probe.py / ab-recall-load2.out）：4 条共享前缀 prompt 入池 → 8 并发长 filler
覆写 GPU 池 → 重放原 prompt → SCHED 命中 + load DMA。注：短 prompt 直接送 filler 不足覆写时
重放走 GPU cached-free 命中（hit_len=0、computed=96），须足量覆写才产生 load——与 offload/README
「cached-free 块 hash 保留」坑记载一致。
