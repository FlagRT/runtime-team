## 1. 结论摘要

1. **环境验证通过**：8× P800 OAM（昆仑芯 KL3，96GB HBM/卡），driver 5.0.21.47 / XPU-RT 10.2；容器内 xpytorch（torch 2.9.0+cu129，CUDA 兼容）可见 8 卡，flag_gems 自动识别 vendor=kunlunxin。
2. **代码版本（分支）依赖结论**：P800 使用 **flagos-ai 上游 kunlunxin 栈**（非 FlagRT dev-1.0 昇腾线）：
   - 参考栈（本机生产/开发容器实测）：Python 3.10.18 + torch 2.9.0+cu129 + vllm 0.13.0 + vllm-plugin-fl 0.1.0（editable）+ flag_gems 4.2.1rc0（= flagos-ai FlagGems @73c5aff1，即 v4.2.1.rc.0-177）+ flagcx 0.10.0 + flagtree(triton xpu) 0.6.1
   - FlagRT dev-1.0 基线（VERSIONS.md，910c 验证）在 P800 的差距：vllm-plugin-FL 无 kunlunxin vendor 条目且配 vllm 0.20.2（P800 是 0.13）；Torch-FL 无 xpu 后端且 torch 锁 ≥2.10 与 P800 的 2.9.0 冲突；**P800 栈的 torch_plugin 0.1.0 不含 torch_fl → flagos 显存池（FLAGOS_USE_CACHING_ALLOCATOR / memory_stats）在 P800 缺失**，allocator 画像暂无法复现（V2 前置缺口）
3. **原型跑通（推理链路 + V1 画像，vendor 算子路径）**：Qwen2.5-1.5B-Instruct 单卡，模型加载 ~20s，加载后 HBM 92.49GiB；KV cache 预分配 **3,047,568 tokens（81.38 GiB）**；短/长序列与并发均正常——**不复现 910c 的长序列 prefill P0**（910c: 2048×4 并发 22min 未完成；P800: 4×2048 并发 2.5s @3292 tok/s）。
4. **两个待办缺口**：① flag_gems（flagos）算子路径在 profile_run 触发 KL3 kernel 异常（status 719），疑似需宿主侧 `echo 1 > /proc/kunlun/dev4/dma_excp_mask`（sudo，triton 警告明确指向）或对齐生产 triton 3.0.0+03c4c9be；② 910c 原版探针（dev/memory/probes、benchmarks）未入库，本次为按 README/方案重建的最小版，待 910c 原件到位后替换重跑。

## 5. V1 画像结果（vendor 路径 · 卡1 · Qwen2.5-1.5B-Instruct · gpu_mem_util=0.9）

| 阶段 | 耗时 | HBM |
|---|---|---|
| 加载 | ~20s（加载后） | 92.49 GiB |
| 预热 2×8tok | 0.43s | 92.49 GiB |
| 128 tok | 1.19s（~108 tok/s 输出侧） | 92.49 GiB |
| 1024 tok | 1.18s | 92.49 GiB |
| 4096 tok | 1.23s（prefill 3354 tok/s） | 92.49 GiB |
| 8192 tok | 1.29s（prefill 6439 tok/s） | 92.49 GiB |
| 并发 4×2048 | 2.51s（prefill 3292 tok/s，输出 102.9 tok/s） | 92.49 GiB |

- KV cache 预分配：**3,047,568 tokens / 81.38 GiB**（vLLM 日志），最大并发 93× @32k/请求
- HBM 全流程恒定 92.49GiB：KV 池整块预分配、请求不涨显存——与 910c 结论一致（KV 是显存大头且整块分配）
- **与 910c 关键差异**：910c 首次 attention 初始化 437s + 2048×4 并发 prefill 22min 未完成（P0）；P800 无首 init 长尾（预热 0.43s）、并发长 prefill 2.5s 完成 → **P0 未在 P800 复现**（但需注意 910c P0 与 flag_gems ascend 算子/调度交互有关，P800 vendor 路径不能完全证伪）
