## 实测与复核

| 批次 | 结果 | 含义 |
|---|---|---|
| 历史 Qwen3-Embedding | 单卡基线与对应采集输出一致；24 份输出哈希及有限值复核通过 | 同栈输出检查，不是独立数学精度参考 |
| 历史 OneRec 单卡 | 32 步生成；A/A 1,280 个边界一致，max_abs=0 | 重复确定性，不等于单卡/双卡一致 |
| 历史 OneRec TP2 | FlagCX / NCCL 兼容层完成；每 rank 32 步，2,304 AllReduce、32 AllGather | 双 rank 内部一致，不判定与单卡数值等价 |
| 两机软件回归 | 各 Inference 33 passed；Base 380 passed / 1 skipped；Operation 167 passed；分发 14 passed；Gloo 1 passed | 各套分别统计；软件测试不替代硬件模型运行 |
| 整合历史产物复核 | 168 份 Store、51 组历史双卡记录，共 342 条操作：321 成功、21 失败 | 21 条失败在原分支复现同退出码、同 stderr；不是 342 个模型测试通过 |
| klx2 整合新单卡 | Qwen / OneRec 基线、perf、accuracy、perf-lite、窗口化与有限路由组合；35 条命令成功，11 份对照输出相等 | 代表性组合，不是全部配置穷举；16 个带哈希输出的有限值/形状校验通过 |
| klx1 整合新单卡 | Qwen 在 model.to(cuda) 阶段未完成；纯 Transformers 同镜像也复现 | 框架外复现，不足以确定硬件/驱动细分根因 |
| 整合新 TP2 | 未执行，缺同机两张可用零显存卡 | 不以历史报告重建替代新双卡实测 |

## 开放问题

| 问题 | 当前边界与下一步 |
|---|---|
| P800-INF-007 | OneRec 第 14 token：单卡 6741、TP2 5582；BF16 并列和更早隐藏状态差异需分开分析；保留标准策略，不为对齐输出改变计算 |
| P800-INF-006 | capture loss、时钟误差上界与通信调用关联不完整，性能 `not_qualified` |
| klx1 模型搬运 | 基础 torch 分配可用、模型搬运阻塞；存在更早 C2C 重试日志，但因果未证实，待健康设备复测 |
| 历史依赖与失败 | 部分 Store 缺原逻辑路径 capture；独立只读映射后通过不改写历史缺失记录 |
| 新模型 | 当前生成入口仅登记 OneRec；更多模型需按统一协议逐项验证 |
