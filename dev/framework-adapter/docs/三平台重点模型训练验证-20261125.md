## 未通过项怎么处理？

- **昆仑芯 DIN、DCN-Mix：**指定数据的原生训练各通过 3 步。重复运行时 NumPy/SciPy 依赖与对照不一致，框架拒绝比较，本轮未取得相同依赖下的替换与回退回执。下一轮固定依赖后分别验证 DIN 预测层、DCN-Mix 两个单项和组合。此前 DCN-Mix 在合成数据上三种配置均通过；如果包括历史输入，累计替换与回退是 20/27，指定数据上仍是 19/27。
- **昆仑芯 BGE-M3、昇腾 Reranker：**前者类型 embedding 独立反向未达到误差要求；模型关闭和缺审核各通过 3 步，未开启。后者四卡原生、关闭和缺审核各通过 3 步；第 0 层 SiLU 候选确有前向 8 次（含重算）、反向 4 次命中，但首步输入归一化权重的梯度在裁剪前有 363/4,096 项超阈、裁剪后仍有 69 项。各 rank 均未更新，不计开启通过；这也不能单凭该次输入归因于 SiLU 实现。
- **昇腾、昆仑芯 LightGCN：**两者均在原生 `torch.sparse.mm` 前向失败，0 步更新。昇腾的 COO/CSR 分别报后端不支持 `aten::addmm` / `aten::addmm.out`；昆仑芯本轮报 `invalid device function`。两者都还没执行替换，不能据此认定同一底层故障。
