# 公共适配包开发记录（本地，未发布）

## 当前范围

`src/flagrt_adapter`是唯一实现：policy负责逐算子环境与能力准入，records读取经审核的证据包，bridge复用注册生命周期、原生回退、一阶autograd及事件记录。
`probes/silu_policy.py`与`silu_training_adapter.py`保留旧import入口，不再复制实现。
包不包含FlagGems内核、device-context源码、模型、驱动或凭证；runtime和gems由调用者注入。torch及厂商依赖由锁定基座提供，pip不得自动替换它们。

第二算子为sigmoid。已只读核对锁定FlagGems源码：
[f7ae8e6的sigmoid前反向](https://github.com/FlagOpen/FlagGems/blob/f7ae8e6b934a33ec1ccaf2c9aae71edf205f8fb4/src/flag_gems/ops/sigmoid.py)。
其反向签名为sigmoid_backward(grad_output, output)，因此保存前向输出；SiLU保存输入。源码有接口不等于该芯片编译/精度通过。
当前拦截F.silu、torch.sigmoid、F.sigmoid；不声称覆盖Tensor.sigmoid、任意ATen入口、融合或编译图。
