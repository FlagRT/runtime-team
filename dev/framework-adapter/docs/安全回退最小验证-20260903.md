# 安全回退最小验证（2026-09-03）

## 本次改动

在 `vllm-plugin-FL/vllm_fl/dispatch` 增加两项控制：

1. 候选实现可声明 `supports_inputs`，调度器根据实际输入在执行前跳过不兼容实现。
2. 候选实现可声明 `runtime_fallback_safe=False`，可能产生副作用的实现执行失败后不再调用其他后端重试。

Ascend 路径的 `rotary_embedding` 默认原地修改输入，已标记为禁止运行时重试，避免失败后重复施加 Rotary Embedding。

## 测试结果

- Python 语法检查和 `git diff --check`：通过。
- FlagGems 容器内运行 `test_types.py` 和 `test_manager.py`：`60 passed`。
- 额外覆盖场景：
  - 输入不兼容时跳过首选实现，且不将其记为失败；
  - strict 模式仍执行输入能力检查，但不进行失败后的运行时重试；
  - 有副作用实现失败后立即返回原异常，不调用下一候选实现。
