# PPU DeepFM训练与安全准入验证

日期：2026-11-10；顾宬方向。本地材料，未提交推送。

## 结论

公共DeepFM已在PPU完成原生三步训练。原生重复、关闭适配、缺模型审核三种对照各294项逐值一致，后两种配置正确保留原生，目标算子调用为0。

直接使用FlagGems sigmoid的独立候选训练，在第1步参数更新后超差，未获得模型准入；当前该DeepFM配置继续使用原生。失败发生在独立目标调用路径，不经过本方向ElementwiseAdapter。这里记录数值现象，不认定算子或编译器存在缺陷，不改内核、不放宽容差。

入口：[case与复现顺序](../cases/ppu-deepfm/README.md)，[结构化摘要](evidence-ppu-deepfm-20261110/summary.json)，[限定审核](../cases/ppu-deepfm/review-20261110/)，[实际baseline/demo](../cases/ppu-deepfm/demo/README.md)。

原生重复/关闭/缺审核使用atol=rtol=0；候选沿用既有模型判据atol=1e-5、rtol=1e-4。没有创建passed模型审核，也没有把独立候选测试当作正式“开启模式通过”。本轮资格记录仅新增sigmoid的这个形状，不继承上午32×64单算子的范围。

## 数值差异及处置

- 首个失败位置：step1/state/mlp.mlp.0.bias，shape400，317个元素超差，最大绝对差0.001755736768245697。
- 同一偏置的梯度最大差1.4901161193847656e-7，在现有梯度容差内；第1步预测/loss和全部17份梯度也通过了既定比较。
- 可观察到的是：更新前差异小，Adam更新后偏置差异放大。尚未归因到具体算子内核、编译器或优化器数值敏感性。
- 独立候选失败时已发生1次参数更新；探针停止，未尝试在该进程内切回原生、回滚或继续训练。后续两条原生路径是新容器、新模型初始化。
- 保存完整失败偏置actual/reference张量及差异样本；原生294份张量也全部备份。失败模型资格显式记录为failed；强制启用的CPU检查拒绝启动。

下一步仅需整理最小数值复现或向相关方向确认支持条件；不以修改上游算子为本方向当前任务。

## 运行与异常记录

全部阶段先核镜像和空卡，使用公共baseline export及up.sh --strict；单卡、断网、8GiB主存、480秒探针上限。根盘余量约12GiB，数据放本人/bmcp_lvm_fs持久目录。

1. 默认SSH报Can't assign requested address；VPN路由和地址仍在。显式绑定当时VPN地址后连接成功，未重启VPN或修改网络。未进一步判定默认连接失败根因。
2. 资格-01/-03、native-01在创建容器前被原32MiB门控拒绝。复查无进程闲卡有26～59MiB底噪，改为连续三次无进程、0%利用率、≤64MiB；0MiB但有PID也拒绝。保留原拦截记录，不修改数值阈值。
3. 资格-02因探针梯度向量仍为2048而shape改为32，准备数据时失败；修正后新输入运行资格-04，追加CPU检查覆盖该失误。不是算子失败。
4. model-input01/02/03/04各自冻结，不覆盖历史输入。03/04的模型执行代码一致，04仅增加审核配置；01/02的失败和门控记录保留。

本轮创建7个本人容器，收尾均Exited、Pid0、OOMKilled=false。容器退出137来自结束常驻sleep容器；实际成功探针退出0，独立数值失败探针退出1。未操作他人容器或共享镜像。
