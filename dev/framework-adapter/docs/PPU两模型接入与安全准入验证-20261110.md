# PPU Qwen与OneRec接入、安全准入验证

实验日期：2026-11-10。顾宬 / cgu135。本轮完成PPU两模型限定配置验证；本报告和case尚未发布。

## 验证内容

补齐PPU的Qwen3-Embedding-0.6B与OneRec-8B两项模型测试。使用完整预训练权重、固定合成输入，比较损失、所有参数的梯度及更新后的参数。沿用既有模型配置与容差，不改算子内核。

| 项目 | Qwen0.6B | OneRec-8B |
|---|---|---|
| 精度/输入 | FP32，batch1、seq32 | BF16，batch1、seq16 |
| 优化器 | AdamW，lr1e-5，梯度裁剪1.0 | SGD，lr0.01，非重入梯度检查点 |
| 模型判据 | atol1e-5、rtol1e-4 | atol1e-3、rtol1e-2 |
| SiLU形状 | 1×32×3072 | 1×16×12288 |
| 独立算子资格 | 3次前向/反向通过 | 3次前向/反向通过 |
| 原生训练 | 3步，1863项对照张量 | 3步，2397项对照张量 |
| 原生重复 | 3步，1863项逐值一致 | 3步，2397项逐值一致 |
| 替换候选 | 第1步梯度超差，更新前停止 | 第1步梯度超差，更新前停止 |
| 关闭替换 | 3步，1863项逐值一致，目标0调用 | 3步，2397项逐值一致，目标0调用 |
| 开启但缺模型审核 | 3步，1863项逐值一致，目标0调用 | 3步，2397项逐值一致，目标0调用 |

原生重复、关闭及缺审核路径采用逐值一致判据。算子资格采用既有单算子判据：FP32 1e-5/1e-4，BF16 2e-2/2e-2；与模型级判据分开。关闭路径记录experimental_disabled，缺审核路径记录workload_unverified，两者均为0次目标调用，所有模型轮次退出后分发器恢复。

## Qwen候选结果

第1步实际命中28次SiLU前向、28次反向，退出后dispatcher恢复。首次失败位于`model.layers.2.mlp.down_proj.weight`梯度，shape1024×3072，共12个元素超差，整个张量最大绝对差为3.35693359375e-4。优化器更新次数为0。

已将该环境与模型配置记录为failed审核；2项CPU控制确认普通配置保留原生、严格配置以workload_denied拒绝。候选实验中的数值检查是离线资格验证，不是生产运行时自动比较梯度。实际模型级开关/缺审核验证与CPU审核决策分别记录。

该现象与P800 Qwen历史失败落在同一层的同名梯度，但误差和数量不同；尚未定位到同一根因，不直接归为编译器或算子缺陷。失败数据交给相应方向核对，本轮不修内核或调整阈值。

## OneRec候选结果

完整8B模型原生及原生重复各3步通过，2397项逐值一致。候选第1步实际命中36次SiLU前向、36次反向，首次失败位于`model.embed_tokens.weight`梯度，28460个元素超差，整个张量最大绝对差为0.28125；优化器更新次数为0，退出后dispatcher恢复。独立SiLU前反向资格通过不能代替模型级数值审核。

已保存failed模型审核，2项CPU控制确认普通配置保留原生、严格配置拒绝。本轮先验证安全路径，不调整算子内核或模型容差；具体差异归属待后续最小复现定位。

## 执行异常与保留记录

- VPN曾缺路由或短时SSH超时；恢复后检查旧任务再继续，没有重叠训练。
- Qwen首轮打包含Mac隐藏元数据，被wheel数量检查拦截，未建容器。之后使用COPYFILE_DISABLE=1与--no-xattrs重新打包，失败输入不覆盖。
- OneRec重复首试被过期sudo票据在启动前拦截；重新认证后使用新运行ID。
- 查到共享OneRec之前的下载尝试已停止，部分下载文件保留且未用于训练。没有操作他人容器或修改共享模型。
