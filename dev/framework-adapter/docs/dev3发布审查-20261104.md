## 复现核验

先按独立仓PACKAGE.md执行build_local.py，再从产物source/独立重建。随后运行audit.py，传入 --repo、--build、--rebuild、--hardware-wheel、--direction 和不存在的 --output 路径。原始实测wheel保存在本方向实验归档；没有该制品时仍可做构建/CPU测试，负载对照需取得制品。

严格拒绝和配置变更失效的公共入口硬件测试是下一轮补充项；当前已有对应CPU控制。训练v3目标编译的shmem问题保留原报告跟踪。
