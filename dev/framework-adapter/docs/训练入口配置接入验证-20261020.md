## 结论边界

- 是训练入口的机制集成，不是新增业务训练效果或性能优化；随机token不代表Embedding检索任务。
- 上游只保存四位小数loss，不保存本轮逐张量梯度/权重；不能由loss相同声称逐值等价。10-18单进程逐张量证据独立保留，不充作本轮新增。
- 真实GEMS日志计数与适配计数交叉核对；只计适配函数被调用不足以证明内核执行。
- 开启组每次调用包含同步/临时注册，首次运行包含编译；原始吞吐只留作诊断，不作性能验收或加速比。
- 缺少资格是执行前选择原生；执行后异常停止，不盲目重试原生。完整三级回退、多平台、融合算子、长训练仍未验收。
- 本地控制回归57项通过：策略10、桥接12、记录7、多算子6、训练配置/作用域5、官方case/结果核验6、v3启动控制11。均为CPU/模拟控制，不能混写成57项NPU实验。
