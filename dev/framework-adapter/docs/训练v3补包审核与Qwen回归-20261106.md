# 训练v3补包审核与Qwen回归

日期：2026-11-06；顾宬 / cgu135。本地验证材料，未提交或推送。

## 结论

训练v3补装cann-shmem 1.6.0后，已将补包纳入环境审核，并完成SiLU开关及Qwen 0.6B双rank训练回归。关闭时使用原生实现，开启且审核通过时调用FlagGems，缺少审核时保留原生。三种模型路径均完成3步。

这次解决的是“镜像相同、补包不同却被当成同一环境”的问题：启动时核对补包版本、wheel SHA、实际导入位置和安装文件，再匹配该环境的算子与模型审核。原来未补包的训练v3仍保持已知编译失败拦截。

## 模型和入口

- 权重：Qwen3-Embedding-0.6B；实际公共训练入口通过`AutoModelForCausalLM`加载Qwen3，随机token输入、语言模型loss、AdamW。不是检索数据集训练或效果评测。
- 固定公共runtime：`719de8cbaea75691b38ad87d6706a949e045b892`；入口`runtime/proto/proto_train_leg.py` SHA `67c5365654a3f0d0ea077f06ebe267acbc947b1ae5db79a95ff4ca15d6b58e06`。
- FP32、每rank batch1、seq32、3步、LR1e-5、2 ranks/HCCL；SiLU形状`[1,32,3072]`。实际loss约17.0600→14.4921。
- 使用已安装wheel的`torch.distributed.run --nproc_per_node=2 --module flagrt_adapter.train_cli`。公共训练源码未改；新增callback接口的跨组接线仍按接口计划推进。
- 独立资格探针使用既有`qualify_public_training.py`，先得到数值证据，再审核；生产配置没有跳过模型审核的开关。
