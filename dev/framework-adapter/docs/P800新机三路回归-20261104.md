日期：2026-11-04。顾宬方向；本轮结果仅保存在本地，未提交、未推送。

## 结论

新152机已完成本方向的有限训练回归：DeepFM FP32、batch32、3步合成数据训练，关闭、开启、不满足模型审核条件三路均通过。开启确实调用FlagGems sigmoid前反向；关闭和不满足条件时保持原生。三路各294项对照均逐值一致，不是只验证程序能启动。

这不是新增模型覆盖，也不等于GEMM补丁、完整env/v1、分布式训练或完整三级回退通过。

## 执行结果

| 路径 | 训练步数 | 实际调用/原因 | 数值与恢复 |
|---|---:|---|---|
| 新机原生基线 | 3 | 全部厂商原生 | 保存294项原生对照张量；不是294项对比成绩 |
| 原生重复 | 3 | 目标0次 | 294/294逐值一致；更新及恢复检查通过 |
| 关闭 off | 3 | 目标0次；每步sigmoid原因experimental_disabled | 294/294逐值一致；退出恢复通过 |
| 开启 on | 3 | 3次FlagGems sigmoid前向 + 3次反向；每步各1次 | 294/294通过，实测最大绝对差0；退出恢复通过 |
| 不满足条件 unknown | 3 | 目标0次；每步原因workload_unverified，保留原生 | 294/294逐值一致；退出恢复通过 |

三路用户指定配置共9步、882项对照；另有原生基线和原生重复各3步。每步98项：prediction、loss、17个梯度、28个模型状态（含BatchNorm缓冲区）、51个Adam状态。目标原定阈值atol=1e-5、rtol=1e-4未放宽；原生类路径要求逐值一致。三步loss依次为1.1338770389556885、0.7584530115127563、1.0672987699508667，仅验证调用与回归，不评价CTR质量。

训练前已在新机完成：

- 环境导入和原生前反向smoke通过；原生SiLU对CPU最大前向/反向差分别约4.77e-7/1.19e-7。
- sigmoid形状16、32，FP32/FP16/BF16共6组、每组3次；18次目标前向及18次反向通过，最大差均0，注册退出恢复通过。这是单算子资格实验，不是18个算子。
- 本地case控制34/34通过；与新机硬件成绩分开计数。

## 审核与安全边界

先跑新机原生与资格探针，再比较环境和实际workload身份。实际镜像、后端、编译器、provider内容、模型文件、训练配置、后端源码及算子组合与已有DeepFM审核严格匹配，才允许受控on回归。使用原10-29审核包，没有自动生成passed、改模型标签或补写证据掩盖不匹配。

unknown配置故意只提供Qwen模型审核：虽然sigmoid单算子有资格，DeepFM模型审核不匹配，仍必须走原生。它验证的是“模型资格不满足”的分支，不代表所有版本错配、运行中异常及芯片级恢复均已覆盖。

7个本人测试容器均已核实停止、Pid=0；4号卡结束时恢复0MiB/0%，没有删除容器或其他人的数据。SSH控制连接已关闭，无后台训练任务。原生参考张量约17MiB压缩包及103个轻量证据文件已取回并校验；服务器原件保留。
