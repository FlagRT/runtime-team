# 910C算子接入与回退原型复现说明

负责人：顾宬

整理日期：2026-10-09；实机结果日期：2026-09-22

本文说明已发布原型的实现入口、运行条件、测试命令和结果判据。覆盖PyTorch + Transformers eager推理，不包含vLLM服务、Megatron训练或新版设备原型回归成绩。

## 验证范围和结果

| 测试 | 数量及结果 |
|---|---|
| 原生NPU基线 | 2组模型输入、8组模型来源算子用例通过 |
| FlagGems独立对照 | 8组通过：SiLU及隐藏层/Q/K RMSNorm各2种形状，不是8种算子 |
| NPU执行前回退 | 4类通过：关闭、未准入、当前策略不支持的FP32输入、非连续布局 |
| 模型开关 | 2组输入×关闭/仅SiLU共4组配置通过，隐藏状态及Embedding与原生一致，退出后恢复 |
| CPU控制测试 | 15项通过；包含开关、冲突、恢复、缺库及异常不重跑，部分异常使用mock |
| RMSNorm分组 | 仅Q/K的2组通过；仅隐藏层的2组隐藏状态超差。诊断完成不等于全部通过 |

控制回归不重复计数，226次RMSNorm旁路观测是调用次数，不是独立用例数。4类回退不是4种硬件故障。FP32被排除是当前适配策略，不表示FlagGems不支持FP32。

## 源码入口

已发布源码固定在[runtime-team@2aad264](https://github.com/FlagRT/runtime-team/tree/2aad264/dev/framework-adapter/probes)。

| 文件 | 作用 |
|---|---|
| `probes/qwen_scoped_adapter.py` | 精确识别模型模块，保存原生forward，按条件调用目标，退出恢复 |
| `probes/qwen_embedding_baseline.py` | 原生基线；经device-context选择ascend并初始化设备 |
| `probes/qwen_gems_validation.py` | 独立算子、回退条件、模型开关对照 |
| `probes/test_qwen_scoped_adapter.py` | CPU控制逻辑测试 |
| `probes/qwen_rms_ablation.py` | Q/K与隐藏层RMSNorm分组替换 |
| `probes/qwen_rms_shadow.py` | 原生路径同输入旁路数值观测 |
| `probes/run_checks.sh` | 统一执行入口，不安装依赖、不自动起容器 |

当前接入为模块实例级forward适配，不是全局ATen注册。适配器默认不启用目标算子；保守验证显式启用SiLU，RMSNorm仅在实验模式使用。

## 命令与判据

以下示例使用完整仓库内的统一入口，路径变量由复现者填写；不是自动部署脚本。Python环境须具备上表依赖。新结果目录避免覆盖旧证据。

```bash
# 填入本次实际路径；仓库必须包含完整probes目录。
export REPO_ROOT=/path/to/runtime-team
export MODEL_DIR=/path/to/verified-model
export DC_ROOT=/path/to/device-context/prototype
export GEMS_SRC=/path/to/FlagGems/src
export TASK_DEPS=/path/to/optional-dependencies

export TORCH_DEVICE_BACKEND_AUTOLOAD=0
export GEMS_VENDOR=ascend
export PYTHONPATH="$TASK_DEPS:$GEMS_SRC"
cd "$REPO_ROOT"
test -d "$MODEL_DIR" && test -d "$DC_ROOT/runtime" && test -d "$GEMS_SRC"
RESULT_DIR=$(mktemp -d /tmp/framework-adapter-repro-XXXXXX)
printf '%s\n' "$RESULT_DIR"
```

准备条件不满足时停止，不继续下列测试。每条命令单独检查返回码、日志及结果字段。

```bash
# 1. 原生NPU基线
timeout -k 5 300 bash dev/framework-adapter/probes/run_checks.sh model-baseline \
  --model "$MODEL_DIR" --device npu:0 --dtype float16 \
  --runtime-root "$DC_ROOT" --out "$RESULT_DIR/native.json" \
  >"$RESULT_DIR/native.log" 2>&1

# 2. CPU控制测试，不执行目标NPU算子
timeout -k 5 90 bash dev/framework-adapter/probes/run_checks.sh qwen-controls \
  --junitxml="$RESULT_DIR/controls.xml" >"$RESULT_DIR/controls.log" 2>&1

# 3. 8组算子、4类回退、4组保守模型配置
timeout -k 5 300 bash dev/framework-adapter/probes/run_checks.sh qwen-gems \
  --model "$MODEL_DIR" --runtime-root "$DC_ROOT" --dtype float16 \
  --out "$RESULT_DIR/safe.json" >"$RESULT_DIR/safe.log" 2>&1

# 4. RMSNorm分组诊断，预期可能存在数值失败
timeout -k 5 180 bash dev/framework-adapter/probes/run_checks.sh rms-ablation \
  --model "$MODEL_DIR" --runtime-root "$DC_ROOT" \
  --out "$RESULT_DIR/ablation.json" >"$RESULT_DIR/ablation.log" 2>&1

# 5. 同输入旁路统计
timeout -k 5 240 bash dev/framework-adapter/probes/run_checks.sh rms-shadow \
  --model "$MODEL_DIR" --runtime-root "$DC_ROOT" --dtype float16 \
  --out "$RESULT_DIR/shadow.json" >"$RESULT_DIR/shadow.log" 2>&1
```

| 入口 | 核验重点 |
|---|---|
| 原生基线 | 设备初始化成功、模型输出有限、2组模型与8组算子结果 |
| qwen-controls | 15项控制测试通过；不能计作NPU测试 |
| qwen-gems | operator_cases、fallback_cases、model_cases与路由；目标真正完成、回退不调用目标、退出恢复 |
| rms-ablation | 每组within_tolerance；历史Q/K两项通过、隐藏层两项失败；退出0和completed只表示诊断完成 |
| rms-shadow | 原生模型输出未改变、逐次误差统计；旁路结果不能代替全模型替换验收 |

FP16历史诊断阈值为atol=rtol=0.005，待算子/精度方向确认，不能为使测试通过而直接放宽。超时、设备错误、数值超差分别报告。执行异常后不在原调用内换实现重试。

本地无设备检查另用 `run_checks.sh local`、`run_checks.sh metadata-tests`，不能替代上述实机验证。收集结果后保存环境身份、源码及模型哈希、JSON/XML和日志；容器内临时目录须及时归档至本人持久目录。
