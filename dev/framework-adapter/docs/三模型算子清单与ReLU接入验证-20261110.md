# 三模型算子清单与ReLU接入验证

实验日期：2026-11-10。顾宬方向。本轮先采实际调用，再选择可接的已有实现；不修改算子内核、公共模型或既有训练数值阈值。

## 实际调用清单

在PPU上对三个完整模型各运行一次原生训练步骤，记录前向、反向和优化器。采集器同时观察Python入口和ATen重载，包含调用次数、输入/输出形状、精度、stride及模块样本。三个步骤均完成，签名未截断。采集模式不用于性能测量。

| 模型与固定配置 | 参数量 | 前向ATen种数 / 调用数 | 反向ATen种数 / 调用数 | 优化器种数 / 调用数 |
|---|---:|---:|---:|---:|
| DeepFM，batch32，FP32，Adam | 421452 | 19 / 48 | 19 / 88 | 12 / 206 |
| Qwen3-Embedding-0.6B，batch1 seq32，FP32，AdamW | 595776512 | 43 / 3179 | 25 / 5522 | 18 / 4658 |
| OneRec-8B，batch1 seq16，BF16，SGD | 8391013376 | 44 / 4324 | 33 / 14653 | 3 / 401 |

Qwen和OneRec复用既有`AutoModelForCausalLM`短训练入口与完整权重，使用合成token及语言模型损失；DeepFM为公共源码、固定随机初始化和合成类别/标签。OneRec开启非重入梯度检查点，反向计数包含重算的前向操作。各阶段的种数有交集，不能相加当作去重后的模型算子总数。

完整逐项表见[算子清单](evidence-operator-inventory-20261110/算子清单-20261110.md)，精确形状与源码注册对应见[机器清单](evidence-operator-inventory-20261110/inventory-comparison.json)。原始Python入口、模块样本和模型身份在本地/远端证据包，路径见HANDOFF。

## 与已有实现的对应及选择

源码核对固定为FlagGems 4.2.1rc0（源73c5aff1，wheel SHA见下）及[FlagOP 2591d081](https://github.com/FLAG-OP/FlagOS-OP/tree/2591d081188d88c2ef75c2798f263186ec3837e2/ops)。FlagOP的catalog更新至11-04，列16项增量条目，自述不是完整算子矩阵。表中“有”只表示源码提供相应入口，硬件/模型资格另测。

| 实际调用与次数（每次模型前向） | 可用源码入口 | 本轮处理 / 后续选择 |
|---|---|---|
| DeepFM ReLU 3次，FP32 32×400；反向threshold_backward 3次 | FlagGems `relu`、`threshold_backward` | 本轮扩展；不用不存在的`aten.relu_backward` |
| DeepFM sigmoid 1次；Qwen/OneRec SiLU 28/36次 | FlagGems同名及反向入口 | 已有适配入口；保留此前各自成功/失败证据，不混入ReLU结果 |
| embedding：DeepFM 2次，Qwen/OneRec各1次 | FlagGems embedding；FlagOP `ops/embedding/register.py::register_a1` | 下一批优先：先核padding、重复索引、dense/sparse梯度、scale_grad_by_freq、注册撤销和前反向契约 |
| `_softmax`：Qwen/OneRec各28/36次，均FP32，形状1×16×32×32 / 1×32×16×16 | FlagGems `softmax`与`softmax_backward`注册到对应ATen入口 | 下一批候选：需支持dim、dtype及反向签名，不能直接套现有一元适配器 |
| linear：DeepFM落到addmm 4次；Qwen/OneRec主要落到mm 197/253次 | FlagGems addmm/mm/bmm | 暂不一次替换全部矩阵乘；先固定布局、精度和梯度契约，再独立数值验证 |
| DeepFM BatchNorm / dropout各3次 | FlagGems有相关注册；FlagOP另有dropout入口 | 暂缓：运行状态更新、随机数和反向语义需要专门约定 |

两点避免接错：

- 本轮Qwen/OneRec使用eager attention，实际是bmm、softmax等基础操作，没有直接SDPA调用。FlagOP提供SDPA实现，也不能直接声称替换命中；不为了制造命中改动本轮attention配置。
- 模型RMSNorm实际分解成pow、mean、rsqrt、mul等操作。不能凭模块名称当成同名ATen RMSNorm；自定义/融合替换继续按原边界暂缓。

三模型embedding具体输入：DeepFM权重3850×16、3850×1及索引32×5；Qwen权重151669×1024及索引1×32；OneRec权重176384×4096及索引1×16。FlagOP的PPU embedding路径含厂商原生委托，接入前应按其真实实现说明记录，不把它误写成全新Triton内核。

## ReLU扩展与验证

功能包增加`F.relu`、`torch.relu`、`Tensor.relu`非原位接入；反向显式调用`aten.threshold_backward(grad, saved_input, 0)`。继续复用逐调用准入、临时注册、退出恢复及异常停止。输入非有限时保留原生（严格模式拒绝），目标路径收到非有限梯度时停止。没有增加自写数学内核。

- 安装包CPU控制152项通过，本次新增6项（3个入口、非有限输入/严格模式、非有限梯度、原位边界及配置）。清单/路由检查工具7项CPU控制通过。
- PPU FP32 32×400单算子资格3次通过，前向/反向与原生及CPU对照最大差均0；包含正负数及正负零，数值判据atol=rtol=0。
- 关闭、开启、缺资格单算子三路通过；开启命中目标前反向各1次，另外两路目标0调用，三路退出注册恢复及作用域外原生检查通过。
- DeepFM模型资格：新原生参考与重复各3步，重复294项逐值一致；ReLU候选3步、294项比较最大差0，前反向各9次命中。原生更新幅度大于0，模型实际完成参数更新。
- 限定模型审核后，关闭/开启/缺模型审核各3步、各294项比较最大差0。开启前反向各9次目标命中；关闭原因experimental_disabled、缺审核原因workload_unverified，均目标0调用；所有步骤的sigmoid保持原生，退出恢复通过。

本轮有效模型输入下的6组（原生、重复、候选、关闭、开启、缺审核）均完成3步。原始记录另保留旧检查器下的原生、重复和失败候选，不重复计为新增能力。离线核验见[摘要](evidence-operator-inventory-20261110/summary.json)，审核材料在[case review](../cases/operator-inventory/review-20261110/)。

ReLU实验只替换3处ReLU，模型sigmoid仍走原生；它与之前sigmoid替换导致参数超差是不同配置，历史失败记录保留。

首次模型候选`relu-candidate-01`在检查器断言处停止：ReLU前反向各3次真实命中、sigmoid按计划原生1次、注册已恢复，但旧断言错误要求所有被观察到的算子都必须走目标。该次0参数更新、尚未进入数值比较。修正仅限本方向测试检查器，改为精确核对“ReLU目标3+3、sigmoid原生1”；增加CPU控制并使用新input04重新建立原生参考，不复用旧探针身份的审核。失败日志完整保留，不记为数值超差。
