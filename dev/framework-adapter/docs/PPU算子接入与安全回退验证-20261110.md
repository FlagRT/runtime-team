PPU上SiLU、sigmoid的FlagGems前反向已跑通：每个算子测试FP32、FP16、BF16，每组重复3次，共18组对照通过。适配包已补PPU身份准入，本地安装包146项测试通过。

## 实验做了什么

固定shape32×64、输入为[-5,5]等距序列、反向输出梯度为[-1,1]等距序列。每种dtype先量化输入，再以该输入的CPU FP32计算为参考，同时对照PPU原生输出及梯度。单次测试直接注册FlagGems前向/反向实现，结束检查dispatcher恢复原状；日志独立统计真实GEMS函数命中。

| 算子 | 精度 | 重复数 | 与PPU原生前向最大绝对差 | 反向最大绝对差 | 结果 |
|---|---|---:|---:|---:|---|
| SiLU | FP32 | 3 | 9.54e-7 | 3.58e-7 | 通过 |
| SiLU | FP16 | 3 | 3.05e-5 | 0 | 通过 |
| SiLU | BF16 | 3 | 0 | 6.10e-5 | 通过 |
| sigmoid | FP32 | 3 | 1.19e-7 | 1.02e-7 | 通过 |
| sigmoid | FP16 | 3 | 0 | 3.05e-5 | 通过 |
| sigmoid | BF16 | 3 | 0 | 2.44e-4 | 通过 |

总计18次前向、18次反向真实GEMS命中，18次注册退出恢复通过。CPU参考对照同样通过，完整逐项数据见[原始结果](../cases/ppu-unary/review-20261110/qualification-result.json)。运行前固定容差：FP32 atol/rtol=1e-5/1e-4，FP16=2e-3/2e-3，BF16=2e-2/2e-2；未放宽。

执行者核对全部18项后，显式保存[6条审核记录](../cases/ppu-unary/review-20261110/records.json)，只覆盖该环境、两算子、三精度、shape32×64。审核加载器核对原始结果SHA `27fff36bc025ee3df132c76520266e5d03e9a291ceec31adecf368bec66c5e97`。资格与下列三路分开执行、分开计数。
