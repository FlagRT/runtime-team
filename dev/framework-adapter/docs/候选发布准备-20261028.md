## 复现入口

功能仓已有torch/setuptools/wheel/pip的环境执行：

```bash
python tools/build_local.py --output /absolute/path/to/new-output
```

协调仓本方向执行以下CPU检查：

```bash
python -m unittest discover -s probes -p test_rank_failure_checks.py
python -m unittest discover -s cases/ascend-official-unary/assets -p 'test_*.py'
python -m unittest discover -s tools -p test_run_validation.py
python -m unittest discover -s cases/ascend-train-v3/assets -p test_runner.py
```

NPU复现走[官方case](../cases/ascend-official-unary/README.md)，显式指定精确wheel、两张协调好的设备及新输出目录，使用rank-failure阶段和guarded-ranks。本次发布准备未连接服务器或重跑硬件。
